# Real.Island

Настольный островок для Windows. В корне находятся статический сайт, готовый Real.Island.exe и архив Real.Island-Source.zip с исходниками и скриптом сборки.

## GitHub Pages

Поместите файлы из архива в корень нужной ветки. В настройках репозитория откройте Pages и выберите публикацию из этой ветки и папки / (root). Кнопки загрузки используют относительный путь к Real.Island.exe.

## Сборка

Распакуйте Real.Island-Source.zip. В PowerShell перейдите в папку source и выполните .\work\build.ps1. Сборка использует WPF и компилятор .NET Framework из Windows. Готовый файл появится в source/outputs. После обновления замените EXE в корне сайта.

## Установка и удаление

Запустите Real.Island.exe. Кнопка «Запустить» открывает островок на текущий сеанс. Кнопка «Установить» копирует программу в локальную папку приложений пользователя, включает автозапуск и добавляет запись в список установленных приложений Windows. В списке приложений выберите Real.Island и нажмите «Удалить».
