Запускать при входе в систему
Разреши управление плеером: Системные настройки → Конфиденциальность и безопасность → Автоматизация → Real Island → Музыка, Spotify, браузер.
Чтобы остров видел уведомления, включи Real Island в Системные настройки → Конфиденциальность и безопасность → Полный доступ к диску (если его нет в списке, нажми + и выбери программу), затем выйди из Real Island и открой снова.
Чтобы кнопки управляли SoundCloud: в Chrome меню Вид → Разработчик → «Разрешить JavaScript из событий Apple Events»; в Safari меню Разработка → «Разрешить JavaScript из событий Apple Events».
Остров показывает Apple Music, Spotify и SoundCloud в браузере, а входящие звонки Discord, Telegram, WhatsApp, Viber, Zoom, Teams, Skype, Signal, FaceTime и других, если программа присылает уведомление о звонке. Полоски басса — анимация, пока играет музыка. Обычные баннеры macOS при этом остаются, их можно выключить в настройках уведомлений.
